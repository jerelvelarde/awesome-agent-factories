# Contribution Guidelines

Thanks for helping make **Awesome Agent Factories** better! Please make sure your suggestion belongs here and follows the format below before opening a pull request.

## What belongs here

This list covers **frameworks, platforms, and tools for building, generating, and orchestrating AI agents** — plus the protocols, observability, and learning resources around them. It does *not* list individual deployed agents or general LLM tooling unrelated to building agents.

An entry should be:

- **Genuinely recommendable** — something you have used or would personally endorse.
- **Actively maintained** — no archived, deprecated, or abandoned projects.
- **Documented** — it must have a README or docs that explain how to use it.
- **Relevant** — it helps people produce, run, or operate agents.

## Adding an entry

1. Fork the repo and create a branch.
2. Add your entry to the most fitting section, keeping each section alphabetical where practical.
3. Use this exact format:

   ```
   - [Name](https://link) - Description ending with a period.
   ```

4. Keep the description to one sentence that explains **why** the project is worth someone's time, not just what it is.
5. Make sure the link resolves and points to the canonical source (the GitHub repo for open-source projects, the product page otherwise).

## Quality checks

- One entry per pull request when possible, so each can be discussed on its merits.
- Check spelling and grammar; descriptions end with a period.
- Run [`awesome-lint`](https://github.com/sindresorhus/awesome-lint) locally if you can: `npx awesome-lint`.

## Removing or updating entries

If a project has gone unmaintained, changed scope, or moved, please open a pull request to update or remove it with a short note explaining why.

Thank you for contributing!
